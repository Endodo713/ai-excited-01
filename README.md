# Shark in the Mirror

A great white shark bursts through a bathroom mirror, jaws open, water
exploding out of the shattered glass — while a man in a towel recoils in
shock. An impossible creature erupting into an everyday scene, one big
central subject that reads clearly even at small size.

An entry for [make.fun ai-excited-01](https://make.fun/bounty/ai-excited-01).

## How it works

`main.py` (Python 3.13, standard library only) copies the image
`entry.png` next to it into `$MAKEFUN_OUTPUT_DIR/entry.png`. The program
runs twice and both runs write identical bytes.
